# Academic Answer Quality Checker

An NLP-based web application that evaluates a student's answer against a model answer.

## Features

- Semantic similarity analysis
- Key-point coverage analysis
- Grammar evaluation
- Student answer evaluation
- Web-based interface

## Tech Stack

- Python
- Flask
- Scikit-learn
- LanguageTool
- HTML
- CSS
- JavaScript
